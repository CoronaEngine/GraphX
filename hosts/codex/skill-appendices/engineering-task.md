## Codex host execution

- Invoke Skills with `$skill-name` syntax.
- Dispatch Implementation and Review through fresh visible Codex tasks in the same local checkout. Never fork the main conversation or use a separate worktree by default.
- Reuse a worker only when exactly one task has the deterministic title. Multiple matches are ambiguous and require the declared fallback.
- Continue the same Implementer task for `{{skill:documentation-sync}}`. Use the task link as the worker reference and the task's stable session ID as its attestation.
